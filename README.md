---

## 📋 Descripción del Proyecto

**Travel Network Graphs** modela una red de transporte entre ciudades usando **estructuras de grafos** implementadas desde cero en C++.  
El proyecto aplica los principios de **Programación Orientada a Objetos (POO)** y permite gestionar ciudades y viajes de forma dinámica.

Las funcionalidades principales incluyen:

- **Insertar** una ciudad en el grafo.
- **Insertar** un viaje nuevo entre ciudades.
- **Obtener el grado** de un nodo (ciudad).
- **Comprobar adyacencia** entre dos ciudades.
- **Mostrar** el grafo completo con todas sus conexiones.
- **Lectura de datos** desde ficheros para inicialización automática del grafo.

## ⚙️ Compilación y Ejecución

Clonar el repositorio:

```bash
git clone https://github.com/sorgazb/Travel_Network_Graphs.git
cd Travel_Network_Graphs/RSVGraphs
```

Compilar con g++:

```bash
g++ -o travel_network *.cpp
```

Ejecutar:

```bash
./travel_network
```
